**Задание 9. Обнаружение аномалий с использованием Autoencoder**

Autoencoder представляет собой нейронную сеть, обучаемую восстанавливать входные данные.

При обучении на нормальных данных сеть хорошо восстанавливает типичные наблюдения.

Если на вход подаются аномальные данные, ошибка восстановления значительно возрастает.

**Шаг 1. Импортируйте библиотеки**

import torch

import torch.nn as nn

**Шаг 2. Подготовьте данные**

X_tensor = torch.FloatTensor(X)

**Шаг 3. Создайте модель**

class AutoEncoder(nn.Module):

def \_\_init\_\_(self):

super().\_\_init\_\_()

self.encoder = nn.Sequential(

nn.Linear(6,4),

nn.ReLU(),

nn.Linear(4,2)

)

self.decoder = nn.Sequential(

nn.Linear(2,4),

nn.ReLU(),

nn.Linear(4,6)

)

def forward(self,x):

x=self.encoder(x)

x=self.decoder(x)

return x

**Шаг 4. Создайте объект модели**

model = AutoEncoder()

**Шаг 5. Настройте обучение**

criterion = nn.MSELoss()

optimizer = torch.optim.Adam(

model.parameters(),

lr=0.001

)

**Шаг 6. Выполните обучение**

for epoch in range(100):

output = model(X_tensor)

loss = criterion(

output,

X_tensor

)

optimizer.zero_grad()

loss.backward()

optimizer.step()

После обучения значение ошибки должно постепенно уменьшаться.
