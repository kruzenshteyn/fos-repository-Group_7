# Модуль 3. Разработка моделей машинного обучения

**Объём:** 54 часа  
**Целевой уровень освоения:** С / П  

## Цель модуля

Сформировать навыки полного цикла разработки моделей для задач умного дома: от формализации сценария и выбора класса моделей до обучения, валидации, анализа ошибок и оптимизации под Edge.

## Содержание

- Классические алгоритмы МО (классификация, регрессия, кластеризация)
- Обучение без учителя (anomaly detection, Isolation Forest и др.)
- Глубокие сети для временных рядов (LSTM, CNN)
- Компьютерное зрение и NLP в сценариях умного дома
- Обучение с подкреплением (базовые подходы)
- Валидация, анализ ошибок, transfer learning, quantization / pruning

**Роль:** ML Engineer

## Оценочные средства

- Практические работы с моделями ИИ (рубежный контроль) — до **15 баллов**
- Рекомендуемый baseline: [воспроизводимый пример Isolation Forest](../resources/software/examples/isolation-forest/README.md)

## Ожидаемые результаты

После модуля студент способен:
1. Формализовать бытовой сценарий как задачу МО / DL.
2. Выбрать и обучить модель (включая unsupervised и базовый RL).
3. Провести валидацию, проанализировать ошибки и определить область применения.
4. Подготовить модель к развёртыванию на Edge (оптимизация).
