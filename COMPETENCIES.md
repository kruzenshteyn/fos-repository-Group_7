# Компетенции КРМ 3.0 (исправленная версия)

> Исправлено в соответствии с экспертной рецензией: устранены неверные расшифровки кодов КРМ.  
> Источник истины — таблица КРМ версии 3.0 (файл `КРМ-версия3.0.xlsx` в репозитории).

## Основные целевые компетенции дисциплины

### Машинное обучение (ML)

| Код | Наименование | Краткое описание в контексте дисциплины |
|-----|--------------|------------------------------------------|
| **ML-2** | Классические алгоритмы машинного обучения / Разработка базовых решений | Выбор и применение подходящего класса моделей (классификация, регрессия, кластеризация) для задач умного дома |
| **ML-3** | Методы повышения устойчивости, надёжности и безопасности алгоритмов МО | Анализ ошибок, определение области применения, устойчивость к шуму сенсорных данных |
| **ML-4** | Обучение без учителя (unsupervised learning) | Кластеризация сценариев поведения, обнаружение аномалий в сенсорных потоках, снижение размерности |
| **ML-6** | Обучение с подкреплением (reinforcement learning) | Оптимизация управления устройствами умного дома, адаптивные политики энергосбережения |

### Глубокое обучение (DL)

| Код | Наименование | Краткое описание в контексте дисциплины |
|-----|--------------|------------------------------------------|
| **DL-1** | Нейронные сети, глубокие нейронные сети | Архитектуры LSTM/CNN для временных рядов сенсоров, основы обучения |
| **DL-3** | Компьютерное зрение | Распознавание событий/объектов по камерам умного дома, детекция присутствия |
| **DL-4** | Обработка естественного языка (NLP) | Голосовые интерфейсы, обработка команд, семантический анализ сценариев |

### Жизненный цикл и безопасность

| Код | Наименование | Краткое описание в контексте дисциплины |
|-----|--------------|------------------------------------------|
| **LC-5** | Жизненный цикл ИИ-систем | Полный цикл: формализация → данные → модель → развёртывание → мониторинг |
| **AI S-1** | Безопасность и надёжность ИИ | Анализ рисков, приватность данных, безопасный контроль человеком (human-in-the-loop) |

## Связь с ролями (трудовые функции)

- **ML Engineer** — преимущественно ML-2, ML-3, ML-4, ML-6, DL-1, DL-3, DL-4
- **Data Engineer (IoT)** — подготовка данных, качество, потоки (связано с ML-4, LC-5)
- **AI Architect** — архитектура Device/Edge/Fog/Cloud, интеграция, LC-5, AI S-1

## Результаты обучения (согласованы с компетенциями)

По завершении дисциплины обучающийся способен:

1. Формализовать бытовой сценарий как задачу ИИ (ML-2, LC-5).
2. Выбрать архитектуру системы Device / Edge / Fog / Cloud (AI Architect + LC-5).
3. Разработать и адаптировать модель машинного обучения, включая unsupervised и RL (ML-2, ML-4, ML-6, DL-1).
4. Организовать сбор и обработку сенсорных данных с контролем качества.
5. Интегрировать ИИ-компоненты с платформой автоматизации (Home Assistant) и Edge-устройствами.
6. Применять компьютерное зрение и NLP в сценариях умного дома (DL-3, DL-4).
7. Анализировать ошибки модели, определять границы применения и обеспечивать безопасность (ML-3, AI S-1).
8. Документировать архитектуру, данные, модели и результаты (LC-5).

## Примечание по использованию

- В модели измерения результатов обучения (README / MEASUREMENT_MODEL) указываются **коды компетенций КРМ**, а не коды трудовых функций.
- Трудовые функции / роли указываются отдельно для контекста.
- Уровни освоения: **Б** (базовый), **С** (средний), **П** (продвинутый) — указываются однозначно.
