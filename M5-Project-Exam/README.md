# Модуль 5. Проектная работа, экзамен и защита

**Объём:** 32 часа  
**Целевой уровень освоения:** П (продвинутый)  

## Цель модуля

Интегрировать все навыки курса в командный проект полного цикла ИИ-функции умного дома, пройти peer-review, сдать экзамен и защитить прототип.

## Содержание

- Командная разработка прототипа (полный цикл: сценарий → данные → модель → Edge/HA → документация)
- Peer-review работ
- Подготовка презентации и демонстрации
- Экзамен (теория + практика)
- Защита проекта перед комиссией

## Компетенции КРМ

Все компетенции, заявленные в модулях 1–4 (LC-5, AI S-1, ML-2…ML-6, DL-1, DL-3, DL-4 и др.).

**Роли:** ML Engineer + AI Architect + Data Engineer (в зависимости от вклада участника)

## Оценочные средства и баллы

| Компонент | Баллы |
|-----------|-------|
| Peer-review | 5 |
| Экзамен | 20 |
| Защита проекта | 25 |
| **Итого по модулю** | **50** (из 100 по курсу) |

Подробные требования — в [PROJECT_REQUIREMENTS.md](../PROJECT_REQUIREMENTS.md) и [ASSESSMENT_TOOLS.md](../ASSESSMENT_TOOLS.md).

## Ожидаемые результаты

После модуля студент способен:
1. В составе команды реализовать работающий прототип ИИ-функции умного дома.
2. Документировать архитектуру, данные, модель, риски и результаты.
3. Пройти peer-review и аргументированно защитить решение.
4. Продемонстрировать понимание полного жизненного цикла и границ применения системы.
