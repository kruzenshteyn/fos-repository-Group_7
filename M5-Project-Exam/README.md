# Модуль 5. Проект, защита и экзамен

**Объём:** 32 часа  
**Контроль:** peer review — 5 баллов, проект и защита — 25, экзамен — 20

## Цель

Подтвердить способность команды создать и защитить воспроизводимый прототип полного цикла, а каждого участника — объяснить архитектурные, модельные, инженерные и этические решения.

## Содержание

- [Цифровая этика и UX](lecture-5-1.md)
- [Сквозной проект](practice-5-2.md)
- анализ данных, модели, интеграции, рисков и ограничений;
- peer review, защита и экзамен.

## Индикаторы КРМ

`LC-2.1 (С)`, `LC-3.1 (С)`, `LC-5.1 (С)`, `SS-1.1 (Б)`, `SS-1.2 (С)`, `AI S-1.1 (Б)`.

Дополнительные результаты М1–М4 могут подтверждаться проектом, но не заменяют обязательные контрольные точки соответствующих модулей.
