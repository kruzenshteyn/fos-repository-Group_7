# Занятие 2.5 (сокращенная редакция)

## Голосовой интерфейс умного дома

> **Данный файл является началом сокращённой редакции лекции.**

## Архитектура голосового помощника

Современный голосовой интерфейс представляет собой конвейер обработки информации:

**Wake Word → ASR → NLU → Dialog Manager → TTS**

- **Wake Word** — обнаружение ключевой фразы активации.
- **ASR** — преобразование речи в текст.
- **NLU** — определение намерения пользователя (Intent) и извлечение параметров (Entities/Slots).
- **Dialog Manager** — управление диалогом, заполнение недостающих параметров и учет контекста.
- **TTS** — синтез речевого ответа.

## Wake Word

Основная задача — обнаружить обращение пользователя с минимальным энергопотреблением.

Типовой конвейер:

Микрофон → FFT → MFCC → компактная CNN → решение.

Для Edge AI применяются TinyML-модели (Porcupine, OpenWakeWord и др.).

Основные показатели качества:

- FAR — ложные срабатывания;
- FRR — пропуски;
- Detection Latency.

## ASR

Автоматическое распознавание речи преобразует аудио в текст.

Современные модели:

- Whisper;
- wav2vec 2.0;
- Vosk;
- NVIDIA NeMo.

Основные метрики:

- WER;
- CER;
- RTF.

## NLU

После получения текста выполняются:

- предварительная обработка;
- регулярные выражения;
- токенизация;
- морфологический анализ;
- синтаксический анализ;
- Intent Classification;
- Named Entity Recognition.

На выходе формируется структура:

```
Intent = Lighting_ON
Room = Спальня
Brightness = 50
```

## Dialog Manager

Обеспечивает:

- хранение состояния диалога;
- заполнение слотов;
- работу с контекстом;
- разрешение неоднозначностей;
- управление несколькими устройствами.

Современные системы используют правила, ML и LLM.

## Контекст

При интерпретации команд учитываются:

- местоположение пользователя;
- время;
- предыдущий диалог;
- профиль пользователя;
- состояние устройств.

## Современные библиотеки

| Компонент | Примеры |
|---|---|
| Wake Word | Porcupine, OpenWakeWord |
| ASR | Whisper, Vosk |
| NLP | spaCy, Natasha, pymorphy2 |
| LLM/NLU | BERT, RuBERT, Transformers |
| Dialog | Rasa, Dialogflow |
| TTS | Piper, Coqui TTS |

## Выводы

Архитектура голосового интерфейса включает пять взаимосвязанных этапов: Wake Word, ASR, NLU, Dialog Manager и TTS. Для систем умного дома наибольшее значение имеют локальная обработка, учет контекста и применение современных предобученных моделей NLP.
