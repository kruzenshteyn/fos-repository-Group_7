# 8. Оценочные задания по темам

## 8.1. Тема «Обработка временных рядов»

### Задание 1. Анализ качества данных

Дан временной ряд температуры помещения с минутным интервалом.

Необходимо:

1. проверить временную метку;
2. определить пропуски;
3. обнаружить выбросы;
4. выбрать способ обработки;
5. объяснить возможные риски автоматического удаления выбросов.

Проверяемые индикаторы: ML-2.2, PL-1.2.

### Задание 2. Формирование признаков

Для прогноза энергопотребления необходимо сформировать признаки:

- час суток;
- день недели;
- выходной день;
- значение за предыдущий час;
- скользящее среднее.

Обучающийся должен объяснить назначение каждого признака.

Проверяемый индикатор: ML-2.2.

### Задание 3. Оценка прогноза

Даны значения:

- MAE = 0,48;
- RMSE = 0,91.

Необходимо объяснить, почему RMSE заметно превышает MAE и что это говорит о распределении ошибок.

Проверяемый индикатор: ML-2.2.

### Практическое задание

Разработать программу, которая:

1. загружает CSV-файл;
2. преобразует столбец timestamp;
3. сортирует данные;
4. проверяет равномерность временного шага;
5. обрабатывает короткие пропуски;
6. создаёт временные признаки;
7. выполняет временное разделение;
8. строит базовый прогноз;
9. рассчитывает MAE и RMSE;
10. строит график результата.

## 8.2. Тема «Кластеризация и понижение размерности»

### Задание 1. Выбор признаков

Для каждого дня доступны:

- среднее энергопотребление;
- максимальное энергопотребление;
- доля ночного потребления;
- продолжительность активности;
- средняя температура.

Необходимо определить, какие признаки использовать для кластеризации суточных режимов.

### Задание 2. Выбор алгоритма

В данных присутствуют шумовые дни и редкие аномальные профили.

Необходимо выбрать подходящий алгоритм кластеризации и обосновать выбор.

### Задание 3. Роль PCA

Необходимо объяснить:

- зачем стандартизировать признаки;
- зачем применять PCA;
- как интерпретировать двумерную визуализацию кластеров.

Проверяемые индикаторы: ML-4.1, PL-1.2.

## 8.3. Тема «Компьютерное зрение»

### Задание 1. Выбор постановки задачи

Для следующих задач определить тип задачи компьютерного зрения:

- определить наличие человека;
- найти всех людей на кадре;
- выделить силуэт человека;
- определить положение суставов;
- распознать лицо пользователя.

### Задание 2. Обнаружение падения

Необходимо объяснить, почему анализ одного кадра недостаточен и какие признаки временной последовательности могут быть использованы.

### Задание 3. Edge-развёртывание

Модель работает со скоростью 5 FPS.

Необходимо предложить способы повышения скорости:

- уменьшение разрешения;
- выбор облегчённой модели;
- пропуск кадров;
- квантизация;
- аппаратное ускорение;
- уменьшение числа обрабатываемых областей.

Проверяемые индикаторы: DL-3.1, LC-5.1.

### Практическое задание

Разработать программу, которая:

1. открывает видеопоток;
2. выполняет детекцию объектов;
3. выводит рамки и классы;
4. измеряет FPS;
5. измеряет задержку;
6. выполняет один вариант оптимизации;
7. сравнивает показатели до и после изменения.

## 8.4. Тема «Голосовой интерфейс»

- Wake Word;
- ASR;
- NLU;

2. включать вопросы по всем основным темам;
3. не оценивать только запоминание терминов;
4. требовать краткое обоснование выбора метода;
5. учитывать корректность постановки задачи;
6. оценивать не только получение результата, но и его проверку;
7. требовать указания метрик;
8. проверять понимание обучающимся собственного кода;
9. учитывать ограничения вычислительной платформы;
10. не снижать оценку только за выбор другой библиотеки, если решение корректно.

# 14. Методические рекомендации обучающемуся

При подготовке к контролю необходимо:

- повторить терминологию;
- понимать назначение каждого метода;
- различать задачи классификации, детекции и сегментации;
- уметь объяснить этапы голосового интерфейса;
- уметь сформулировать RL-задачу;
- повторить метрики MAE, RMSE, FPS, latency и WER;
- подготовить рабочее окружение Python;
- проверить запуск программ;
- сохранить графики и таблицы;
- подготовить краткий вывод.

# 15. Требования к программным работам

Программная работа должна содержать:

- название задачи;
- описание входных данных;
- перечень библиотек;
- исходный код;
- описание последовательности действий;
- результаты;
- метрики;
- визуализацию;
- вывод.

Рекомендуемые библиотеки:

- NumPy;
- pandas;
- matplotlib;
- scikit-learn;
- OpenCV;
- Ultralytics;
- TensorFlow Lite или PyTorch;
- библиотеки для ASR и TTS;
- стандартные библиотеки Python.

Допускается использование альтернативных инструментов при наличии обоснования.

# 16. Требования к академической добросовестности

Обучающийся обязан:

- понимать представленный код;
- указывать использованные источники;
- не выдавать чужую работу за собственную;
- самостоятельно выполнять защиту;
- объяснять назначение основных частей решения;
- уметь изменить параметры решения по требованию преподавателя.

Использование готовых моделей и библиотек допускается, поскольку оценивается не разработка алгоритма с нуля, а корректность выбора, применения и анализа результата.

# 18. Итоговое решение о сформированности результатов

Индикатор считается сформированным, если обучающийся:

- набрал не менее 60% баллов по связанным оценочным средствам;
- выполнил практическую часть;
- продемонстрировал понимание основных понятий;
- смог объяснить выбор метода;
- интерпретировал полученный результат.

При невыполнении одного из обязательных практических элементов преподаватель вправе назначить дополнительное задание по соответствующей теме.
