# Нормативные данные

Каталог содержит актуальную матрицу компетенций и ролей `krm-v3.0.xlsx`, используемую как источник кодов, формулировок индикаторов и целевых уровней.

Учебные датасеты размещаются в [`resources/datasets`](../resources/datasets/README.md), чтобы не смешивать нормативные и экспериментальные данные.
