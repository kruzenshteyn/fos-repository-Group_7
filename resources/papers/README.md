# Научные статьи

Полные тексты сторонних публикаций в репозитории не хранятся и не перелицензируются. Неподтверждённые названия, авторы, годы, DOI и условия доступа не включаются в публичную библиографию.

Для реализации конкретного потока дисциплины преподаватель формирует список публикаций по темам прогнозирования, CV, речи, обучения с подкреплением, обнаружения аномалий, Edge AI и безопасности. До публикации каждая запись проверяется по первичному источнику издателя либо официальному репозиторию конференции.

## Обязательные поля записи

| Поле | Требование |
|---|---|
| Библиография | Авторы, точное название, издание, год и страницы при наличии |
| Устойчивая ссылка | DOI, страница издателя или официальный репозиторий конференции |
| Связь с курсом | Модуль, занятие и точный индикатор КРМ |
| Условия использования | Лицензия открытого доступа либо исходные условия правообладателя |
| Дата проверки | Дата последней проверки метаданных и доступности |

Ссылка на статью не означает разрешение копировать её текст или иллюстрации. В учебные материалы включаются только допустимые цитаты, собственные пересказы и явно разрешённые материалы.
