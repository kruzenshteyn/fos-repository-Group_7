## Правила использования в дисциплине

- LLM разрешены для объяснения концепций, генерации черновиков кода и документации.
- Обязательно указывать в отчёте, какие части созданы/доработаны с помощью ИИ.
- Запрещено сдавать сгенерированный код/текст без понимания и существенной доработки.
- На экзамене и устной защите — только с разрешения преподавателя.

## Требования к добавлению

Укажите модель/сервис, назначение промпта, входные данные, ожидаемый формат результата, ограничения и способ верификации ответа.
