## Требования к новому benchmark

Новый результат добавляется только вместе с:

1. фиксированными входными данными либо проверяемой процедурой их получения;
2. исходным кодом, зависимостями и командой запуска;
3. параметрами эксперимента, seed и описанием среды;
4. baseline, метриками и условиями измерения;
5. текстовым контрольным отчётом и указанием лицензий;
6. правилом, исключающим модели, кэши и сгенерированные предсказания из Git.
