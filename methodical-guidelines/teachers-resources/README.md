# Методические указания преподавателям по ресурсам

## Выбор ресурсов

- Используйте материалы, непосредственно связанные с результатом обучения и оценочным средством.
- Проверяйте доступность ссылки, автора, дату и лицензию до включения ресурса в занятие.
- Не публикуйте персональные, конфиденциальные или лицензионно ограниченные данные.
- Для индустриальных кейсов используйте обезличенные данные либо синтетический эквивалент.

## Воспроизводимость

Программный пример должен содержать исходный код, зависимости, описание входных данных и ожидаемый способ проверки. Обученные модели, кэши и промежуточные таблицы не заменяют воспроизводимый сценарий запуска.
