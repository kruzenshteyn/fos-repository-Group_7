# Рекомендации по переименованию и очистке каталогов

## Переименования (обязательно)

| Текущее имя | Рекомендуемое имя | Причина |
|-------------|-------------------|---------|
| `M3-module-name` | `M3-ML_Models` или `M3-Models_Development` | Убрать placeholder, отразить содержание (разработка моделей МО/DL) |
| `M5-module-name` | `M5-Project_Exam` или `M5-Project_and_Exam` | Убрать placeholder, отразить проект + экзамен |

Команды (выполнить в корне репозитория):

```bash
git mv M3-module-name M3-ML_Models
git mv M5-module-name M5-Project_Exam
```

После переименования обновить все ссылки в README, SYLLABUS, ASSESSMENT_TOOLS и модульных README.

## Очистка

1. Удалить или заменить все вхождения:
   - `[reference:N]`
   - `ChatGPT 5 | Gemini 3 | Nano Banana` и подобные
   - `[НАЗВАНИЕ МОДУЛЯ]`, `[ФИО]`, `[ЗАПОЛНИТЬ]`, `[Название]`

2. Нормализовать имена файлов с кириллицей (если мешают отображению).

3. В каждом модульном README добавить:
   - Краткое описание модуля
   - Ссылки на лекции / практики / КИМ
   - Ожидаемые результаты обучения
   - Связь с компетенциями КРМ

4. В `team/README.md` заполнить реальные ФИО участников и вклад.

5. В `resources/` заполнить подпапки реальными ссылками/файлами или удалить пустые заглушки.

## Добавление кода (для повышения баллов 2.7 и 3.5)

Рекомендуется создать:

```
src/
notebooks/
  01_data_exploration.ipynb
  02_baseline_model.ipynb
  03_edge_optimization.ipynb
requirements.txt
tests/
```

Минимальный baseline должен быть воспроизводим на датасетах из `data/`.
