# Модуль 1. Введение и архитектура ИИ-систем умного дома

**Объём:** 22 часа  
**Контроль:** архитектурный кейс, 10 баллов курса

## Цель

Связать пользовательский сценарий умного дома с сенсорами, данными, ИИ-компонентом, местом инференса и безопасным исполнительным контуром.

## Результат

Обучающийся обосновывает архитектуру «сенсор — данные — модель — решение — исполнитель», выбирает место инференса, проектирует хранение телеметрии и определяет базовые угрозы.
