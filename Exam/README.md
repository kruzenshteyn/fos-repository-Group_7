# Экзамен

Этот каталог содержит единственный официальный комплект экзаменационных материалов дисциплины «Прикладной искусственный интеллект для систем умного дома». Экзаменационные билеты в модульных ФОС и КИМ не дублируются.

## Формат

- Комплект: ровно 10 билетов.
- Каждый билет: два теоретических вопроса по 5 баллов и прикладной кейс на 10 баллов.
- Максимум: 20 баллов курса.
- Подготовка: 30 минут.
- Устный ответ и обсуждение: до 15 минут.
- Билет назначается случайно или по утверждённому преподавателем порядку.
- Дополнительный вопрос допустим только для уточнения представленного ответа и не меняет максимум билета.

## Правила проведения

На экзамене обучающийся демонстрирует индивидуальное понимание полного цикла «сценарий — данные — модель — интеграция — эксплуатация». Использование конспектов, сети, LLM и иных внешних средств допускается только если преподаватель письменно объявил это до экзамена для всей группы. Источники, предоставленные в условии кейса, использовать можно.

Подмена ответа, получение подсказок, передача содержания билета во время экзамена и представление чужого решения как собственного рассматриваются по правилам академической честности образовательной организации. При техническом сбое факт фиксируется, а новая попытка назначается без ухудшения результата по процедуре организации.

Результат сообщается с разбивкой `5 + 5 + 10` и письменной либо электронной обратной связью по рубрике. Апелляция подаётся по установленной образовательной организацией процедуре.
