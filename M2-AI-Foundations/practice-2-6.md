**Цель работы**

Получить практические навыки разработки простейшей системы обработки голосовых команд на языке Python с использованием современных технологий обработки естественного языка. В ходе выполнения работы обучающиеся создадут собственную модель понимания пользовательских команд, интегрируют её с системой автоматизации Home Assistant и реализуют обработку контекстно-зависимых запросов.

**Теоретические сведения**

В данной работе используется архитектура современной голосовой системы управления.

После произнесения пользователем голосовой команды звуковой сигнал сначала преобразуется в текст при помощи модели Whisper. Затем полученный текст передаётся в систему понимания естественного языка Rasa, которая определяет намерение пользователя (Intent), выделяет необходимые сущности (Entities) и формирует структуру команды.

После определения требуемого действия выполняется обращение к Home Assistant посредством REST API. Home Assistant передаёт управляющую команду исполнительному устройству (например, лампе освещения или интеллектуальной розетке). После выполнения действия пользователю возвращается ответ голосового помощника.

В данной работе будет реализована именно такая цепочка обработки информации.

**Использование сущностей (Entities)**

Во многих случаях одной информации об интенте недостаточно.

Например, пользователь может сказать

Включи свет на кухне.

или

Включи свет в спальне.

В обоих случаях интент одинаков.

Различается только помещение.

Подобная информация называется **сущностью (Entity)**.

**Шаг 11. Добавление сущности room**

Измените интент следующим образом.

\- intent: turn_on_light

examples: \|

\- включи свет в \[кухне\](room)

\- включи свет в \[гостиной\](room)

\- включи свет в \[спальне\](room)

\- включи лампу в \[кабинете\](room)

Здесь

room

является именем сущности.

**Шаг 12. Добавление сущности temperature**

**Этап 3. Интеграция Rasa с Home Assistant**

На данном этапе будет реализовано взаимодействие между системой обработки естественного языка Rasa и платформой домашней автоматизации Home Assistant. После завершения этапа пользователь сможет отдавать голосовые команды, которые будут преобразовываться в HTTP-запросы к Home Assistant.

Для обмена данными используется REST API Home Assistant.

**Шаг 1. Подготовка Home Assistant**

Убедитесь, что Home Assistant запущен и доступен через браузер.

Например,

http://192.168.1.100:8123

или

http://localhost:8123

Выполните вход под своей учетной записью.

**Шаг 2. Получение Long-Lived Access Token**

Для обращения к REST API необходим персональный токен доступа.

В Home Assistant выполните следующие действия.

1.  Откройте профиль пользователя.

2.  Перейдите в раздел **Security**.

3.  Найдите раздел **Long-Lived Access Tokens**.

4.  Нажмите **Create Token**.

5.  Укажите имя

Rasa

6.  Скопируйте сформированный токен.

**Важно!**

После закрытия окна токен повторно отображаться не будет.

Сохраните его в отдельный текстовый файл.

**Этап 4. Реализация контекстно-зависимых команд**

На предыдущем этапе голосовой помощник научился распознавать команды и передавать их в Home Assistant. Однако все команды были независимыми друг от друга. Пользователь был вынужден полностью повторять информацию в каждом запросе.

Например,

Включи свет в гостиной.

Сделай яркость света в гостиной 70 процентов.

Выключи свет в гостиной.

Подобный диалог неудобен.

Человек обычно говорит значительно короче.

Например,

Включи свет в гостиной.

Сделай его ярче.

Теперь выключи.

Во втором случае местоимения **его** и **теперь** имеют смысл только с учетом предыдущих реплик. Такая обработка называется **контекстно-зависимой**.

В Rasa сохранение информации о ходе диалога обеспечивается механизмами **Tracker** и **Slots**.

**Шаг 1. Добавление нового слота**

Откройте файл

domain.yml

Добавьте раздел

slots:

current_room:

type: text

mappings:

\- type: custom

current_device:

type: text

mappings:

\- type: custom

После выполнения этого шага Rasa сможет сохранять информацию о последнем выбранном помещении и последнем устройстве.

**Шаг 2. Сохранение информации о помещении**

Добавьте в конец метода

Для использования SlotSet импортируйте его.

В начале файла добавьте

from rasa_sdk.events import SlotSet

Теперь после выполнения команды

Включи свет в спальне.

Rasa автоматически запомнит значение
