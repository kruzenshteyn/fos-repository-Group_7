# Модуль 2. Фундаментальные технологии ИИ для умного дома

**Объём:** 36 часов, включая 18 часов контактной и 18 часов самостоятельной работы
**Контроль:** практические работы, 15 баллов курса

## Цель

Освоить базовые технологии прогнозирования, компьютерного зрения, языка и речи, а также обучения с подкреплением на сценариях умного дома.

## Темы

| Занятия | Тема | Материалы |
|---|---|---|
| 2.1–2.2 | Временные ряды и прогнозирование | [лекция](lecture-2-1.md), [практика](practice-2-2.md) |
| 2.3–2.4 | Компьютерное зрение и Edge-инференс | [лекция](lecture-2-3.md), [практика](practice-2-4.md) |
| 2.5–2.6 | Голосовой интерфейс: ASR, NLU, TTS | [лекция](lecture-2-5.md), [практика](practice-2-6.md) |
| 2.7–2.8 | Обучение с подкреплением для HVAC | [лекция](lecture-2-7.md), [практика](practice-2-8.md) |

## Индикаторы КРМ

`BD-1.2/1.3 (С)`, `ML-2.2/2.3 (С)`, `ML-3.2 (С)`, `ML-4.1 (С)`, `DL-3.1 (Б)`, `DL-4.1 (Б)`, `DL-5.1 (Б)`, `ML-6.1 (Б)`, `PL-1.2 (С)`, `LC-5.1 (Б)`.

## Результат

Обучающийся подготавливает временные данные без утечки будущего, сравнивает модели по метрикам, применяет готовые CV/NLP/ASR-компоненты и формализует RL-задачу управления.
