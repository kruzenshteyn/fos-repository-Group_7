**Краткие теоретические сведения**

Современный умный дом представляет собой распределённую интеллектуальную систему, объединяющую датчики, исполнительные устройства, сетевое оборудование и модели искусственного интеллекта.

ИИ используется для:

- обнаружения вторжений;

- управления энергопотреблением;

- прогнозирования отказов оборудования;

- анализа поведения пользователей;

- принятия решений в режиме реального времени.

Использование искусственного интеллекта повышает функциональные возможности системы, однако одновременно создаёт новые угрозы безопасности.

Основными категориями угроз являются:

- подмена данных датчиков;

- отравление обучающей выборки (**Data Poisoning**);

- обход модели (**Evasion Attack**);

- извлечение модели через API (**Model Extraction**);

- восстановление персональных данных (**Membership Inference**).

Для систематического анализа подобных угроз применяются международные методики **STRIDE** и **MITRE ATLAS**, а управление рисками рекомендуется выполнять в соответствии с требованиями **ГОСТ Р ISO/IEC 27005-2010**, **NIST AI RMF 1.0**, **ПНСТ 836-2023** и актуальных методических документов **ФСТЭК России**.

**Задание 8. Моделирование федеративного обучения (Federated Learning)**

Одним из современных подходов к обеспечению конфиденциальности данных в системах искусственного интеллекта является **Federated Learning (FL)**. В отличие от традиционного централизованного обучения, при федеративном обучении данные пользователей не передаются на центральный сервер. Каждое устройство обучает модель локально, а на сервер отправляются только обновлённые параметры модели.

Такой подход позволяет существенно снизить риск компрометации персональных данных и соответствует требованиям современных систем доверенного искусственного интеллекта.

**Задание 9. Differential Privacy**

Даже при использовании Federated Learning существует возможность восстановления информации о пользователях по обновлениям модели. Для уменьшения данного риска применяется **Differential Privacy (DP)**.

Основная идея Differential Privacy заключается в добавлении контролируемого случайного шума к данным или параметрам модели. Это позволяет скрыть влияние отдельных пользователей на процесс обучения при сохранении общей полезности модели.
