# Прикладной искусственный интеллект для систем умного дома

Репозиторий рабочей программы дисциплины и фонда оценочных средств для бакалавриата (3–4 курс).

| Параметр | Значение |
|---|---|
| Трудоёмкость | 5 ЗЕ, 180 академических часов |
| Язык | Русский |
| Формат | Лекции, практические работы, командный проект |
| Аттестация | Экзамен и защита проекта |
| Максимальный результат | 100 баллов |
