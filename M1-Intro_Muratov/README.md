# Модуль 1. Введение и архитектура ИИ-систем умного дома

**Объём:** 22 часа  
**Автор материалов:** Муратов  
**Целевой уровень освоения:** С (средний)  

## Цель модуля

Сформировать у обучающихся системное понимание архитектуры интеллектуальных функций умного дома: от пользовательского сценария до выбора размещения вычислений (Device / Edge / Fog / Cloud).

## Содержание

- Концепция умного дома и цифровых двойников
- Архитектура «сенсор — данные — модель — решение — исполнительное устройство»
- Выбор платформы и устройств
- Архитектурный кейс

## Ожидаемые результаты

После модуля студент способен:
1. Проанализировать бытовой сценарий и формализовать его как задачу ИИ.
2. Спроектировать архитектуру потоков данных и выбрать уровень размещения вычислений с обоснованием.
3. Учитывать базовые требования безопасности и контроля человеком.
